# Zebra RMS Feedback Updates

This public repository is used only to distribute cryptographically signed updates to installed Zebra RMS Feedback workstations.

Release assets contain:

- `stable.json`, the signed update manifest
- `ZebraRmsFeedback-Update-<version>.zip`, the app-only update

The first-time workstation installer is distributed internally. Zebra CoreScanner, Zebra 123Scan, the private update-signing key, scanner configuration backups, and warehouse data are never published here.
